# CampusOS 🎓

CampusOS is an AI-Powered Institutional Intelligence & Campus Operating Platform designed for colleges and universities. It serves as a centralized hub connecting students, academic clubs, faculty, and administration to foster a thriving campus ecosystem.

## Features ✨
- **Student Portal**: Seamlessly track academics, events, and club activities.
- **Club Management**: Discover, join, and manage campus organizations and their events.
- **Administrative Dashboard**: Gain institutional intelligence and oversee operations efficiently.
- **AI Integration**: Smart event recommendations, automated workflows, and intelligent insights.

## Tech Stack 🛠️
- **Frontend**: React 19, TypeScript, Tailwind CSS
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Charts**: Recharts

## Getting Started 🚀

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation
1. Clone the repository (if you haven't already):
   ```bash
   git clone <your-github-repo-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd CampusOS
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the App
To start the development server, run:
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

## Scripts 📜
- `npm run dev`: Starts the development server.
- `npm run build`: Builds the app for production.
- `npm run lint`: Lints the codebase.
- `npm run preview`: Previews the production build locally.
